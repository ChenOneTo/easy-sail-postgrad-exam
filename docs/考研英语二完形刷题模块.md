# 考研英语二完形刷题模块

> 版本：v1.0 · 日期：2026-11-02
> 范围：英语二 Section I 完形填空（20 空 × 0.5 分 = 10 分），2022–2026 共 5 年。

## 1. 数据来源

构建期读取：

- `{READING_SOURCE_DIR}/{year}-考研英语二真题.md`：20 空逐题答案、正确词、考点、简析。
- `{READING_SOURCE_DIR}/README.md`：五年完形答案速查表，用于交叉校验。
- `reading-source/pdf-text/{year}-英语二-试题.txt`：挖空原文与 A–D 选项。

运行时只读：

`src/assets/exam-cloze/cloze-bank.json`

```bash
npm run build:cloze
```

产物：

- `src/assets/exam-cloze/cloze-bank.json`（5 篇 / 100 空）
- `reading-source/cloze-draft.json`
- `reading-source/cloze-review.csv`

### 数据校对

- 五年答案逐题与解析集表格、README 速查表比对。
- 2022 Q15 `funny`、Q20 `in turn`，2023 Q16 `identify`，2025 Q4/Q5/Q10/Q16 的 OCR 选项已定点修正。
- 2022–2024 扫描卷的粘连词、缺空格（`iskey` / `itcan` / `lifechanges` 等）已在构建脚本的修正表中处理；原文仍建议按 `cloze-review.csv` 抽查。
- 正确词优先取自解析集「正确词/短语」列；答案字母与正确词所在项不一致会进复核清单，当前为 0 条。

## 2. 数据库

Migration **v5**（不改动 v1–v4）：

| 表 | 用途 |
|---|---|
| `exam_cloze_passages` | 5 篇完形原文，`content` 为 JSON 段落数组，空位用 `{{n}}` |
| `exam_cloze_questions` | 100 空：上下文、四选项、答案、正确词、考点、解析 |
| `exam_cloze_sessions` | 练习会话：模式、限时、用时、得分、是否考场时段 |
| `exam_cloze_session_questions` | 会话与空位关联 |
| `exam_cloze_attempts` | 逐空作答明细 |
| `exam_cloze_wrongbook` | 错题本：错因、备注、连续答对次数、掌握状态 |
| `exam_cloze_profile` | 限时秒数、考场时段、题库版本 |

模式：`close`（精读，不限时）/ `timed`（默认 15:00）/ `wrong`（错题重做）。

## 3. 功能

### 题库

- 5 年列表：年份、主题、20 空、词数、错题数、已练状态。
- 每年可「限时 15:00」或「精读」。
- 有未完成会话时显示继续/作废，避免并行会话。

### 作答

- 左侧挖空原文：空位显示题号，点击跳转；已答显示所选字母。
- 右侧当前空：上下文 + A–D 选项 + 20 空答题卡 + 上一空/下一空 + 交卷。
- 选完自动进入下一空；答案实时写入 `exam_cloze_attempts`，退出后可从题库页继续。
- 限时模式墙钟倒计时，不暂停；到点自动交卷；精读模式正计时。
- 记录 `in_exam_slot`（默认 14:00–17:00），统计考场时段正确率。

### 复盘

- 左右分栏：左侧回填正确答案的原文（正确绿色、错误红色并标「你选 X」），右侧单空解析。
- 「错题 / 题目」切换；题号格 + 上一空/下一空。
- 每空显示你的答案、正确答案、正确词、考点、解析；错题可标注错因/备注。
- 支持「重做本空」「重做本篇错题」「重做全部错题」。

### 错题本 / 统计

- 错题按未掌握/已掌握过滤；可改错因、重做、标记掌握、移除。
- 提交时答错与未答自动入库；连续答对 2 次转「已掌握」。
- 统计：练习次数、总正确率、平均用时、今日正确率、按年份正确率、考场时段/时段外正确率、限时完成率、错因分布、最近练习。

## 4. 云同步

独立文件 `easysail-exam-cloze.json`，只含：

- `profile`
- `sessions` / `sessionQuestions` / `attempts` / `wrongbook`

题库本体不入云快照，可从 JSON 重导。已接入自动同步与「设置 → 云同步」；统计页提供手动备份/恢复。
