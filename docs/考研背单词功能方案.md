# 「考研背单词」功能方案

> 版本：v1.0（初稿） · 日期：2026-09-05
> 状态：待评审
> 范围：英语二单词背诵（5054 词 / 26 单元），内置间隔重复算法，替代外挂 Anki

## 一、需求背景

在职考研用户已有「考研计划」（倒计时 + 分科任务 + 阶段规划）与「考研刷题」（数学题库）两模块，但英语复习闭环还缺**单词**这一环——而单词是英语二 70 分目标的底层地基。

现状是用户用外挂 Anki 背词：词表已在仓库（`docs/考研英语/` 三件套），但要装额外软件、手动导入、与应用内学习记录割裂。本方案把词表与调度算法内嵌进 easy-sail-postgrad-exam，让背单词和考研计划/刷题同处一个桌面应用，数据统一备份。

**设计输入**（已就位的三个文件）：

| 文件 | 角色 |
|---|---|
| `背诵计划_105天.md` | 节奏蓝图：核心区 U01–U13 / 基础区 U14–U26、三阶段、每日流程、三条硬规矩 |
| `考研英语_26单元词表.md` | 人读版词表（5192 行，26 单元表格） |
| `考研英语_主词表_Anki导入.tsv` | 机读版词表（5054 行，四列：单词、释义、单元、序号）——**本方案的数据源** |

## 二、设计前提与约束

来自 `背诵计划_105天.md`，必须落到功能逻辑里：

1. **分层，不平均用力**：核心区 U01–U13（2532 词，死磕两轮，见到即知义会拼写）；基础区 U14–U26（2522 词，眼熟即可）。超纲词不背。
2. **三阶段节奏**：阶段一核心区首轮（50 新词/天）→ 阶段二基础区速通（70 新词/天，核心区靠复习维持）→ 阶段三纯复习冲刺（停新词）。
3. **Anki 级调度参数**：新卡 50/天（阶段二 70）、最大复习 200/天、学习步骤 1m/10m、毕业间隔 1 天、简单间隔 4 天、新卡顺序按单元、复习按间隔递增。
4. **每日 60 分钟流程**：前 25 分钟清复习队列 → 30 分钟学新词 → 5 分钟收难词。
5. **三条硬规矩**：①复习优先于新词，欠债不过夜；②不抄写，看读测重复；③考前最后两周停新词。

## 三、已确认的设计决策

| 决策点 | 方案 |
|---|---|
| 调度算法 | **`ts-fsrs`（FSRS-4.5 开源 TS 实现）**，不手写 SM-2；目标保留率 0.9，参数对齐背诵计划的 Anki 配置 |
| 词库来源 | 直接导入 `主词表_Anki导入.tsv`（5054 词，4 列），作为应用静态资源打包，首启检测空库自动灌入 |
| 卡片粒度 | 一词一卡，调度状态独立于词库（词库可重导，调度不丢，按 `word` 唯一键 upsert） |
| 隔离原则 | 全部独立表 `exam_vocab_*`，与 tasks、exam_tasks、exam_questions 零耦合；松引用 `exam_subjects.key='english'` 与 `exam_profile.exam_date`（倒计时复用，不另存考试日） |
| 分区定义 | 硬编码 `core_zone` 标记：U01–U13=1 核心区，U14–U26=0 基础区（导入时按单元号写入，用户不可改分区，只改阶段日期） |
| 阶段配额 | `exam_vocab_profile` 存三阶段起止 + 各阶段新词/天；阶段判定按今天日期落点，每日新词数自动随阶段切换 |
| 卡片方向 | 英→中（默认）/ 中→英 / 双向混合（设置可切）；同词双向时两张独立调度卡 |
| 难词本 | 答错（Again）自动累计，连续 N 次 Again 进难词本；可手动加/移除；难词本单独成池可重刷 |
| AI 能力 | 轻量增强：为难词生成助记/词根拆解/例句（复用 `useAiTask` 链路），不做出题 |
| 云同步 | 独立文件 `easysail-exam-vocab.json`，随自动同步定时备份；词库本体不进快照（可从资源重导） |
| 图标 | 一律 lucide-react（`BookOpen` / `Languages` / `SpellCheck`），无 emoji（遵守开发规范） |

## 四、数据模型（Migration v9，5 张新表）

> 迁移延续 Rust 端 `src-tauri/src/lib.rs` 的 `add_migrations`，当前已应用到 **v7**。v8 已被「考研刷题」方案预定，故本方案用 **v9**；若刷题未先落地，两者顺序按实际开发先后调整，互不冲突（表名无交集）。
> v9 迁移只建表 + 配置种子，**不灌词库**——5054 词由前端首启从静态资源 TSV 导入（见第八节），避免 Rust 端塞 5054 行种子 SQL。

### 4.1 exam_vocab_words —— 词库（静态，可重导）

```sql
CREATE TABLE IF NOT EXISTS exam_vocab_words (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  word TEXT NOT NULL,
  meaning TEXT NOT NULL,
  unit TEXT NOT NULL,                 -- 'U01'..'U26'
  seq INTEGER NOT NULL,               -- 单元内序号
  core_zone INTEGER NOT NULL,         -- 1=核心区(U01-U13) 0=基础区(U14-U26)
  archived INTEGER DEFAULT 0,         -- 1=用户标记弃用（超纲/误收）
  UNIQUE(word)
);
CREATE INDEX IF NOT EXISTS idx_vocab_words_unit ON exam_vocab_words(unit, seq);
CREATE INDEX IF NOT EXISTS idx_vocab_words_zone ON exam_vocab_words(core_zone, archived);
```

### 4.2 exam_vocab_cards —— 调度状态（一词一卡，可双向）

```sql
CREATE TABLE IF NOT EXISTS exam_vocab_cards (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  word_id INTEGER NOT NULL,           -- 关联 exam_vocab_words.id
  direction TEXT NOT NULL DEFAULT 'en2zh'
    CHECK (direction IN ('en2zh','zh2en')),
  state TEXT NOT NULL DEFAULT 'new'
    CHECK (state IN ('new','learning','review','relearning')),
  step_idx INTEGER DEFAULT 0,          -- learning/relearning 步骤索引（0=1m,1=10m）
  due TEXT,                            -- 到期时间 ISO；new=null（按序取）
  stability REAL DEFAULT 0,           -- ts-fsrs 稳定度（天）
  difficulty REAL DEFAULT 0,           -- ts-fsrs 难度（-1..1 归一）
  reps INTEGER DEFAULT 0,             -- 已复习次数（不含 learning）
  lapses INTEGER DEFAULT 0,           -- 遗忘次数
  last_reviewed_at TEXT,
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now')),
  UNIQUE(word_id, direction)
);
CREATE INDEX IF NOT EXISTS idx_vocab_cards_due ON exam_vocab_cards(state, due);
CREATE INDEX IF NOT EXISTS idx_vocab_cards_state ON exam_vocab_cards(state);
```

### 4.3 exam_vocab_reviews —— 复习日志（统计曲线用）

```sql
CREATE TABLE IF NOT EXISTS exam_vocab_reviews (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  card_id INTEGER NOT NULL,
  word_id INTEGER NOT NULL,
  rating INTEGER NOT NULL,             -- 1=Again 2=Hard 3=Good 4=Easy
  state_before TEXT NOT NULL,          -- 评分前卡片状态
  interval_days REAL DEFAULT 0,        -- 本次产出间隔
  duration_ms INTEGER DEFAULT 0,       -- 本卡耗时
  reviewed_at TEXT DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_vocab_rev_day ON exam_vocab_reviews(reviewed_at);
CREATE INDEX IF NOT EXISTS idx_vocab_rev_card ON exam_vocab_reviews(card_id, reviewed_at);
```

### 4.4 exam_vocab_hardwords —— 难词本

```sql
CREATE TABLE IF NOT EXISTS exam_vocab_hardwords (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  word_id INTEGER NOT NULL,
  reason TEXT DEFAULT '',              -- 'again-streak' / 'manual'
  again_streak INTEGER DEFAULT 0,      -- 连续答错次数
  note TEXT DEFAULT '',
  status TEXT DEFAULT 'new' CHECK (status IN ('new','grasped')),
  added_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now')),
  UNIQUE(word_id)
);
CREATE INDEX IF NOT EXISTS idx_vocab_hard_status ON exam_vocab_hardwords(status);
```

### 4.5 exam_vocab_profile —— 全局配置（单例行）

```sql
CREATE TABLE IF NOT EXISTS exam_vocab_profile (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  card_direction TEXT DEFAULT 'en2zh'
    CHECK (card_direction IN ('en2zh','zh2en','both')),
  target_retention REAL DEFAULT 0.9,   -- ts-fsrs 保留率
  max_reviews_per_day INTEGER DEFAULT 200,
  phase1_start TEXT DEFAULT '2026-09-06',
  phase1_end   TEXT DEFAULT '2026-10-26',
  phase1_new_per_day INTEGER DEFAULT 50,
  phase2_start TEXT DEFAULT '2026-10-27',
  phase2_end   TEXT DEFAULT '2026-12-02',
  phase2_new_per_day INTEGER DEFAULT 70,
  phase3_start TEXT DEFAULT '2026-12-03',
  phase3_end   TEXT DEFAULT '2026-12-18',
  phase3_new_per_day INTEGER DEFAULT 0,   -- 冲刺停新词
  last_study_date TEXT,
  streak INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);
INSERT OR IGNORE INTO exam_vocab_profile (id) VALUES (1);
```

阶段默认值与 `背诵计划_105天.md` 三阶段表一一对应；用户可在设置弹窗改阶段日期与配额。

## 五、间隔重复算法（ts-fsrs）

**为什么用库而不是手写**：间隔重复算法的调参极敏感，手写 SM-2 容易出现「复习雪崩」或「间隔虚长」。`ts-fsrs` 是 Anki 当前默认 FSRS-4.5 的成熟 TS 移植，npm 直装，省去算法维护成本，且参数可对齐背诵计划。

**接入方式**：

```ts
import { fsrs, FSRS, Card, Rating, generatorParameters } from 'ts-fsrs';

const params = generatorParameters({ request_retention: 0.9, maximum_interval: 36500 });
const f: FSRS = fsrs(params);
// 评分：Rating.Again=1 Hard=2 Good=3 Easy=4
// const now = new Date();
// const { card, log } = f.repeat(card, now);   // 产出下一张调度状态 + 四个按钮的预览间隔
// card.due / card.stability / card.difficulty / card.reps / card.lapses 写回 exam_vocab_cards
```

**卡片状态机**（ts-fsrs 原生四态）：

```
new ──Good──▶ learning ──Good──▶ review ──Again──▶ relearning ──Good──▶ review
                       (1m/10m)                  (回炉)             (间隔递增)
```

**四按钮语义与默认间隔预览**（对齐 Anki 配置）：

| 按钮 | rating | 语义 | 新卡产出 | 复习卡产出 |
|---|---|---|---|---|
| 重来 | Again | 完全没记住 | 1 分钟后重见 | 标记 lapse，进 relearning（10m），stability 折减 |
| 困难 | Hard | 勉强想起 | 10 分钟后 | 间隔 ×0.7 左右 |
| 良好 | Good | 正常想起 | 1 天后毕业 | 间隔按 stability 推算（主路径） |
| 简单 | Easy | 一眼就会 | 4 天后 | 间隔 ×1.3 |

> `ts-fsrs` 的具体间隔由 stability/difficulty 实时计算，上表为语义说明；毕业间隔 1 天、简单间隔 4 天通过新卡首评产出，与背诵计划一致。

**调度写入**：每次评分后，`f.repeat()` 返回的新 `Card` 字段（state/step_idx/due/stability/difficulty/reps/lapses/last_reviewed_at）整体写回 `exam_vocab_cards`；同时写一条 `exam_vocab_reviews` 日志。

## 六、每日队列调度

每日进入页面时，按以下顺序组装今日待办队列（严格「复习优先于新词」）：

1. **学习中队列**（state='learning' 或 'relearning'，step 到期）：最高优先，先清光。
2. **到期复习队列**（state='review' 且 due ≤ now）：按 due 升序，截断到 `max_reviews_per_day`（默认 200，防雪崩）。
3. **今日新词**：仅当队列 1+2 清完或剩余预算足够时投放。新词数 = 当前阶段配额（阶段一 50 / 阶段二 70 / 阶段三 0）。投放顺序：核心区优先（U01→U13，按 unit/seq），核心区学完再基础区（U14→U26）。

**阶段判定**：取 `exam_vocab_profile` 三阶段起止，今天日期落点决定 `new_per_day`。阶段三（冲刺）`new_per_day=0`，强制停新词，只刷复习——落实硬规矩③。

**Streak 连续天数**：每日首次完成任一卡片即记为「学习日」。`last_study_date` 与今天相邻则 `streak++`，否则 `streak=1`；当天无学习不重置（跨天后再判）。

**欠债提示**：若到期复习数 > max_reviews，顶部红条提示「今日复习超载，建议砍新词保复习」——落实硬规矩①。

**进度预算**：顶部进度卡实时显示 今日新学X/配额、复习Y/到期Z、已耗时、连续N天。

### 7.1 发音播放

WebView2（Edge Chromium 内核）原生支持 Web Speech API，发音**零新增依赖、零 Rust 改动**。

| 路径 | 来源 | 质量 | 依赖 | 用途 |
|---|---|---|---|---|
| 系统 TTS | `window.speechSynthesis` + Windows 自带英文语音 | 合成，略机械 | 离线，无 | 默认主路径 |
| 在线真人 | `new Audio('https://dict.youdao.com/dictvoice?audio='+word+'&type=2').play()` | 真人录音 | 联网，非官方接口 | 可选增强（type=2 美音，type=1 英音） |

- 封装 `src/lib/vocab-tts.ts` 的 `speak(word)`：按设置选系统/在线；在线播放失败（限流/断网）自动 fallback 系统 TTS，不抛错。
- 卡片交互：翻面后自动播一次当前词；正面/翻面都有喇叭按钮（`Volume2` 图标）手动点播；键盘 `S` 键播当前词。
- 设置项：发音源（系统/在线/关闭）、语速（0.7–1.2）、翻面自动播（开关）。
- 数据无改动：发音运行时合成，不落库；在线音频不预缓存（5054 词约 50–150MB，打包不现实）。
- 实现前先验证：在 Tauri webview 跑一行 `speechSynthesis.speak(new SpeechSynthesisUtterance('revolt'))` 确认 WebView2 出声再展开。
- 此能力是后续「听写模式」（第十四节）的前置：听写只是把正面从看单词换成只听音。

子组件（页面内）：`VocabCard` / `UnitGrid` / `HardWordList` / `VocabStats` / `VocabSettingsSheet` / `AiMnemonicSheet`。

## 八、词库导入机制

词表是静态资产，更新频率低，但 5054 行不适合塞进 Rust 迁移 SQL。方案：

1. 把 `主词表_Anki导入.tsv` 复制为前端静态资源 `src/assets/exam-vocab/主词表.tsv`（Vite 打包进应用）。
2. `exam-vocab-store` 初始化时检测 `exam_vocab_words` 是否为空：
   - 空 → `fetch(资源URL)` 取 TSV 文本 → 逐行 split → 按 unit 序号算 `core_zone`（U01–U13=1，U14–U26=0）→ 单事务批量 `INSERT OR IGNORE`（`UNIQUE(word)` 去重）→ 为每词建 `exam_vocab_cards` 默认卡（state='new'）。
   - 非空 → 跳过，直接进入调度。
3. **词表更新（重导）**：设置弹窗「重导词表」按钮，bump 一个本地版本号触发重导。重导按 `word` 唯一键 upsert：新增词追加新卡，已存在词保留全部调度状态不动，词表删除的词标记 `archived` 不强删（保历史日志）。
4. 失败兜底：资源读取失败 → Toast 提示「词表未加载」，页面只读空态，不阻塞应用启动。

> 不走 Rust 端：前端主导数据层是项目现有模式（`exam-db.ts` 全在 TS），且 Vite 资源管线对 .tsv 文本零成本。

## 九、AI 助记（轻量增强）

复用现有 `useAiTask` 请求链路（与考研周计划、刷题出题同模式），新增一条 prompt：

1. `buildVocabMnemonicPrompt(word, meaning)`：System「你是考研英语助记专家，为单词生成 3 行内助记：词根拆解 + 联想口诀 + 一句例句」，输出 JSON `{ mnemonic, roots, sentence }`。
2. `normalizeMnemonicDraft` 校验字段存在性，脏数据降级丢弃不抛错。
3. `generateMnemonic(word)` 走 AbortController + loading，结果挂到卡片背面（可展开折叠）。
4. 可选缓存到 `exam_vocab_words` 扩展字段 `mnemonic`（后续迁移加列），避免重复请求。

**不做的事**：不接入 AI 出题、不接入 AI 释义改写——背单词的核心价值是高频重复，不是 AI 内容；助记仅在难词/重点词上按需触发，控制 token 成本。

## 十一、云同步
