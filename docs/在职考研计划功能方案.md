# 「在职考研计划」功能方案

> 版本：v1.1（定稿） · 日期：2026-08-26
> 状态：开发中
>
> v1.0→v1.1 变更：任务存储由「复用 tasks 表」改为 **独立 exam_tasks 表**，
> 与现有功能零耦合；归属隔离从"过滤排除"简化为"天然隔离"。

## 一、需求背景

为在职考研用户（管理类联考场景：英语 / 数学 / 逻辑）提供专属学习计划模块：
考试倒计时、分科任务管理、阶段规划（基础/强化/冲刺）、每日打卡与时长统计，
并支持 AI 一键生成周计划。

## 二、已确认的设计决策

| 决策点 | 方案 |
|---|---|
| 核心原则 | **不污染现有功能：全部独立表结构，不复用 tasks** |
| 功能深度 | 完整计划系统：阶段规划 + 打卡日历 + 时长统计 |
| 考试倒计时 | 页面顶部常驻，日期可在设置中修改（默认 2026-12-19） |
| AI 能力 | 复用 useAiTask 请求链，生成周计划草稿 → 勾选批量写入 exam_tasks |
| 科目设计 | 表驱动（english/math/logic 种子），扩展政治等零成本 |
| 考试任务能力 | 轻量三态（待学/进行中/已完成）+ 计划日期；不含提醒/重复/星标 |

## 三、数据模型（Migration v5，5 张新表）

### 3.1 exam_profile —— 全局配置（单例行）

```sql
CREATE TABLE IF NOT EXISTS exam_profile (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  exam_date TEXT,                          -- 初试日期 YYYY-MM-DD
  target_note TEXT DEFAULT '',             -- 目标备注（院校/专业/分数）
  daily_goal_minutes INTEGER DEFAULT 120,  -- 每日目标学习时长(分钟)
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);
INSERT OR IGNORE INTO exam_profile (id, exam_date) VALUES (1, '2026-12-19');
```

### 3.2 exam_subjects —— 科目

```sql
CREATE TABLE IF NOT EXISTS exam_subjects (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  key TEXT UNIQUE NOT NULL,       -- english / math / logic
  name TEXT NOT NULL,
  color TEXT NOT NULL,
  sort_order INTEGER DEFAULT 0,
  archived INTEGER DEFAULT 0
);
INSERT OR IGNORE INTO exam_subjects (key, name, color, sort_order) VALUES
  ('english', '英语', '#3B82F6', 0),
  ('math',    '数学', '#F59E0B', 1),
  ('logic',   '逻辑', '#8B5CF6', 2);
```

### 3.3 exam_phases —— 阶段规划

```sql
CREATE TABLE IF NOT EXISTS exam_phases (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  subject_id INTEGER NOT NULL,
  name TEXT NOT NULL,             -- 基础 / 强化 / 冲刺
  start_date TEXT NOT NULL,
  end_date TEXT NOT NULL,
  goal TEXT DEFAULT '',
  sort_order INTEGER DEFAULT 0
);
-- 种子：每科 3 阶段（按默认考试日倒排，用户可编辑）
-- 基础 2026-01-01~08-31 · 强化 09-01~10-31 · 冲刺 11-01~12-19
```

### 3.4 exam_punches —— 打卡记录

```sql
CREATE TABLE IF NOT EXISTS exam_punches (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT NOT NULL,             -- YYYY-MM-DD
  subject_key TEXT NOT NULL,
  minutes INTEGER DEFAULT 0,
  note TEXT DEFAULT '',
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now')),
  UNIQUE(date, subject_key)
);
```

### 3.5 exam_tasks —— 学习任务（独立于 tasks）

```sql
CREATE TABLE IF NOT EXISTS exam_tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  subject_key TEXT NOT NULL,      -- english / math / logic
  title TEXT NOT NULL,
  notes TEXT DEFAULT '',
  status TEXT DEFAULT 'todo'
    CHECK (status IN ('todo', 'doing', 'done')),
  plan_date TEXT,                 -- 计划日期 YYYY-MM-DD
  started_date TEXT,              -- 开始日期
  completed_at TEXT,
  sort_order INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_exam_tasks_subject ON exam_tasks(subject_key, plan_date);
```

## 六、隔离性说明

- 数据层：五张 exam_* 表与 tasks 无外键、无共享值域
- 展示层：考试任务仅存在于考研专区；不出现在首页、日历、看板、回顾页
- 云同步：本期 exam_* 表不参与云备份（后续迭代）

## 七、AI 周计划流程

1. 用户输入需求 → `buildExamPlanPrompt(subjectName, 需求)`
2. 返回 JSON：`{ plans: [{ title, notes, planDate|null }] }`
3. normalizeExamPlanDraft 校验 → 草稿预览（勾选）→ 批量插入 exam_tasks
