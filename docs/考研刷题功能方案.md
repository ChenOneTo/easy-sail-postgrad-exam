# 「考研刷题」功能方案

> 版本：v1.0（初稿） · 日期：2026-09-05
> 状态：待评审
> 范围：先做数学（199 管综数学），后续可扩展英语/逻辑

## 一、需求背景

在职考研用户已有「考研计划」模块（倒计时 + 分科任务 + 阶段规划）。但学习闭环缺**刷题**一环：看完章节笔记无就近练习题、错题散落在 PDF 截图无法统计与重做、不知各章掌握程度。

本方案新增独立「考研刷题」模块，先覆盖 199 管综数学：AI 基于知识库章节内容出题、按章刷题、应用内错题本、正确率统计。

## 二、知识库调研结论（设计前提）

教材《陈剑·数学高分指南》已放入 Obsidian 知识库。调研结论：

| 层 | 内容 | 含题干原文 |
|---|---|---|
| 11 章节笔记 | 考纲/核心公式/题型分类/小节页码/复习要点/解析技巧，callout 承载，公式用反引号行内代码 | 否 |
| MOC 索引 | wiki 链接章节表 + 印刷页↔PDF 页偏移表 + 试卷结构 callout | 否 |
| 页码速查/技巧索引 | 解析分册技巧全文索引、页码速查 | 否 |
| 真题 B / 模拟 A | 年份起始页表 + 复习阶段提示，指向 PDF | 否（纯索引页） |
| 错题本 | 空字段模板（题干为「题目截图或抄写」占位符） | 否 |
| `00 素材/` 两个 PDF | 主教材 + 解析分册 | **仅存于此** |

**关键事实**：题目实体（题干/选项/答案/解析）在所有 markdown 文件中都不存在，只活在两个 PDF 里；且 PDF/OCR 文本里数学公式是失真纯文本（分数、根号、上下标常错）。

三条设计约束：
1. 不能从 markdown 读题——markdown 没有题干。
2. 不直接从 PDF 抽题做主路径——OCR 公式失真，体验不可靠；留作后续探索。
3. 可以从 markdown 读「知识上下文」喂 AI 出题——章节笔记里的公式/方法/易错点是干净结构化文本，正是出题素材。

## 三、已确认的设计决策

| 决策点 | 方案 |
|---|---|
| 题目来源 | AI 基于知识库章节 markdown 生成（主）+ 手动录入真题/教材题（辅）；不读 PDF |
| 题型 | 仅 199 管综数学两种：问题求解（5 选 1）、条件充分性判断（条件(1)(2) 充分性，选项 A-E 固定含义） |
| 章节 taxonomy | 对齐知识库 11 章（算术 2 / 代数 3 / 几何 3 / 数据分析 3），种子表 `exam_drill_chapters` |
| 知识库联动 | 配置「教材目录」后，AI 出题读取该章 md 作为上下文；未配置则降级通用出题 |
| AI 出题质量 | 生成结果一律进预览，用户逐题编辑/删/改答案后才批量入库；不自动入库 |
| 错题本 | 应用内结构化表（错因 5 分类 + 掌握状态 + 重做计数），独立于 Obsidian 错题本.md |
| 隔离原则 | 全部独立表，与 tasks、exam_tasks 零耦合；仅松引用 `exam_subjects.key='math'` |
| 云同步 | 独立文件 `easysail-exam-drill.json`，随自动同步定时备份 |
| 图标 | 一律 lucide-react，无 emoji（遵守开发规范） |

### 4.2 exam_questions —— 题库

```sql
CREATE TABLE IF NOT EXISTS exam_questions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  subject_key TEXT NOT NULL DEFAULT 'math',
  chapter_key TEXT NOT NULL,                  -- 'ch01'.. 关联 exam_drill_chapters.chapter_key
  knowledge_point TEXT DEFAULT '',             -- 考点（如"绝对值性质"）
  qtype TEXT NOT NULL CHECK (qtype IN ('ps','csd')),  -- 问题求解 / 条件充分性判断
  difficulty INTEGER DEFAULT 2,                -- 1简单 2中等 3难
  stem TEXT NOT NULL,                          -- 题干（markdown；csd 题含结论+条件(1)(2)）
  options TEXT NOT NULL DEFAULT '[]',          -- JSON 数组；ps=5选项文本，csd=可空(UI渲染固定含义)
  answer TEXT NOT NULL,                        -- 正确答案 'A'..'E'
  explanation TEXT DEFAULT '',                 -- 解析（markdown）
  source TEXT NOT NULL DEFAULT 'ai',           -- ai / manual / imported
  source_ref TEXT DEFAULT '',                  -- 来源备注（如"主教材 P15 例3"）
  archived INTEGER DEFAULT 0,                  -- 1=用户标记弃用（质量差）
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_exam_q_chapter ON exam_questions(chapter_key, archived);
```

### 4.3 exam_attempts —— 答题记录

```sql
CREATE TABLE IF NOT EXISTS exam_attempts (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  question_id INTEGER NOT NULL,
  user_answer TEXT NOT NULL,           -- 'A'..'E' 或 ''（未答）
  is_correct INTEGER NOT NULL,          -- 0/1
  duration_ms INTEGER DEFAULT 0,        -- 本题耗时毫秒
  session_id TEXT,                      -- 同一次练习会话归组（UUID）
  attempted_at TEXT DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_exam_attempt_q ON exam_attempts(question_id, attempted_at);
```

### 4.4 exam_wrongbook —— 错题本

```sql
CREATE TABLE IF NOT EXISTS exam_wrongbook (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  question_id INTEGER NOT NULL,
  user_answer TEXT DEFAULT '',                  -- 错答
  wrong_reason TEXT DEFAULT '',                 -- concept/calc/typenew/time/csd-trap
  note TEXT DEFAULT '',                          -- 关键步骤/补充
  status TEXT DEFAULT 'new' CHECK (status IN ('new','grasped')),
  review_count INTEGER DEFAULT 0,                -- 重做次数
  last_reviewed_at TEXT,
  added_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now')),
  UNIQUE(question_id)                           -- 同题只留一条；重做更新
);
CREATE INDEX IF NOT EXISTS idx_exam_wrong_status ON exam_wrongbook(status, added_at);
```

错因 5 分类对齐 Obsidian 错题本模板：`concept`(概念不清) / `calc`(计算失误) / `typenew`(题型没见过) / `time`(时间不够) / `csd-trap`(条件充分性陷阱)。

## 五、题型与判分规则

199 管综数学全卷 25 题×3 分=75 分，限时约 60 分钟，不允许用计算器。仅两种题型：

| 题型 | qtype | 题量 | 结构 | 答案 |
|---|---|---|---|---|
| 问题求解 | `ps` | 15 | 题干 + 5 选项(A-E) | 正确选项 A-E |
| 条件充分性判断 | `csd` | 10 | 结论题干 + 条件(1) + 条件(2) | A-E（固定含义见下） |

条件充分性判断选项固定含义（UI 直接渲染，`options` 字段可空）：

- **A**：条件(1)充分，条件(2)不充分
- **B**：条件(2)充分，条件(1)不充分
- **C**：两条件联合才充分，单独都不充分
- **D**：两条件各自充分
- **E**：两条件联合也不充分

判分：`user_answer === answer` 即正确。`csd` 题选项文本由 UI 固定渲染，判分只比字母。

- **错题本视图**：列表 + 错因筛选 + 重做（只刷错题） + 标记已掌握。

- **AI 出题 sheet**：选章节 + 考点(可选) + 题型(ps/csd/混合) + 数量(1-20) → 读取章节 md 上下文 → 生成预览 → 逐题编辑/勾选 → 批量入库。

## 七、知识库联动（AI 出题上下文）

新增「教材目录」配置（localStorage 键 `easysail-exam-kb-dir`），仿现有云盘目录 `getCloudDir` 模式 + 目录选择对话框（`@tauri-apps/plugin-dialog`）。

默认指向知识库教材目录：`D:\我的知识库\我的知识库\考研\管理类考研\备考\数学\陈剑·数学高分指南`。

出题流程：
1. 用户在 AI 出题 sheet 选 chapter_key（如 `ch09`）。
2. 按 chapter_key→文件名映射（`ch09` → `04 数据分析篇\09 第九章 排列组合.md`）拼接路径，Tauri fs 读 md 文本。
3. 截断到合理长度（如前 6000 字，避免超 token），作为 `kbSnippet` 传入 prompt。
4. 未配置教材目录或读取失败 → `kbSnippet` 为空，AI 退化为通用出题（仍可用，但脱离教材）。

`chapter_key→md文件名` 映射表硬编码在 `exam-drill-db.ts` 常量（11 条，与知识库目录结构一一对应）。

## 九、AI 出题流程

复用现有考研周计划的 AI 链路模式（`buildExamPlanPrompt` → `normalizeExamPlanDraft` → `generateExamPlan`），平行新增：

1. `buildPracticeQuestionPrompt(chapterName, knowledgePoint, qtype, count, kbSnippet)`：System 指明「你是 199 管综数学出题专家，只产 ps/csd 两题型，输出 JSON schema」，User 附章节知识上下文 + 出题要求。
2. AI 返回 `{ questions: [{ qtype, stem, options, answer, explanation, knowledgePoint, difficulty }] }`。
3. `normalizePracticeDraft(raw)`：校验 qtype 合法、ps 题 options 长度=5、answer ∈ A-E、剥离非法字段；脏数据降级丢弃不抛错。
4. `generatePracticeQuestions(...)` 在 `useAiTask`，走 AbortController + loading/error。
5. 预览列表：每题可编辑 stem/options/answer/explanation + 勾选是否入库 → 批量 `insertQuestions`。
6. 入库 source='ai'，source_ref 记章节+考点；用户练后若发现题目有误可编辑答案或 `archived=1` 弃用。

**质量约束**：AI 生成的数学题可能算错答案。所有题一律先预览、可编辑；练后用户可标记弃用；错题自动入库时若连续多题「答错且用户改过答案」会提示复核。

## 十、云同步

新增独立云文件 `easysail-exam-drill.json`，结构：

```json
{ "version": 1, "chapters": [...], "questions": [...], "attempts": [...], "wrongbook": [...] }
```

- `saveExamDrillToCloud(snapshot)` / `loadExamDrillFromCloud()` 仿现有 `saveExamToCloud` 模式（Tauri fs + localStorage fallback）。
- `ExamDrillCloudSnapshot` 接口在 `exam-drill-db.ts` 定义；`replaceExamDrillData(snapshot)` 事务整体覆盖（chapters 按 chapter_key 合并，questions/attempts/wrongbook 全量替换）。
- `registerExamDrillGetter` 注册到 cloud.ts，自动同步 loop 里随 exam/health 一起保存。
- 「教材目录」配置不进云快照（每机本机路径，仿云盘目录处理）。

## 十三、后续迭代方向

- **真题套卷模拟**：限时 60 分钟闭卷 25 题套卷模式 + 计分曲线。需先手工录入或 AI 生成贴近真题的套卷题库。
- **PDF 题目导入**：解析 `00 素材/` PDF 抽题；前置解决 OCR 公式失真（LaTeX 化或截图化）。可利用知识库页码速查表（印刷页↔PDF 页）与题号格式（`【例N]`/`N.A`）定位题块。
- **错题间隔复习**：按 Obsidian 错题本模板的「天后/周后/月后」做定时重做提醒，接入现有任务提醒引擎。
- **错题本与 Obsidian 双向同步**：把应用内错题导出为 `错题本.md` 的 `###` 条目格式；或反向读取已填错题。
- **公式渲染升级**：题干/解析里的公式从反引号代码升级为 LaTeX（KaTeX/MathJax）渲染。
- **扩展英语/逻辑刷题**：复用本模块，`subject_key` 加 english/logic 的题型与章节。
- **题目图片**：支持题干附图（截图贴入），弥补纯文本表达不了的几何图。
- **错因热力图 / 考点雷达**：可视化各章/各考点掌握度。
